# Laricas CRM

## Deploy no Vercel (3 passos)

### 1. GitHub
- Crie uma conta em github.com se não tiver
- Clique em "New repository" → nome: laricas-crm → Create
- Faça upload de todos os arquivos desta pasta

### 2. Vercel
- Acesse vercel.com e faça login com sua conta GitHub
- Clique em "Add New Project"
- Selecione o repositório laricas-crm
- Clique em "Deploy" (sem alterar nada)

### 3. Pronto
- O Vercel gera uma URL pública (ex: laricas-crm.vercel.app)
- Abra essa URL, configure o Supabase e importe a lista
